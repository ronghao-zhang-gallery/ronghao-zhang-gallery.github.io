{% comment %} Sets the page language on before the first paint, so the page never flashes another language. Three languages (user, 2026-10-23): English, Simplified Chinese, Traditional Chinese. Uses the visitor's saved choice (lang-switch.js), otherwise their browser language: Chinese for Taiwan, Hong Kong and Macau (or any zh-Hant) gets Traditional, other Chinese gets Simplified. Inline on purpose: an external script would run too late. Each Chinese script has its own web font, loaded only once that language is chosen (the font lists are 100–170 KB each; the fonts themselves come in small pieces from jsDelivr, so only the characters on the page download). The lists are local copies with font-display: block (scripts/make_cjk_font_css.py) and load render-blocking, so a new page never first draws its Chinese in a stand-in font (user, 2026-10-25). window.siteLang.apply() is also used by lang-switch.js. {% endcomment %}
